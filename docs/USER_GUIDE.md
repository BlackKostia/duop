# Посібник користувача Duop

**Duop** — це швидкий двопанельний термінальний файловий менеджер (TUI), написаний повністю на чистому x86-64 асемблері (із compile-time PAL-бекендом для AArch64) без `libc` і сторонніх бібліотек.

Повний довідник клавіш див. у [HOTKEYS.md](HOTKEYS.md) або всередині програми через **`F1` → `Інструкція`** (`Instruction`).

---

## 1. Запуск і параметри командного рядка

```bash
duop [--lang ID] [--choosedir=FILE] [-V|--version] [-L|--license] [-h|--help] [ЛІВА_ТЕКА [ПРАВА_ТЕКА]]
```

- **`ЛІВА_ТЕКА` / `ПРАВА_ТЕКА`** — початкові каталоги лівої та правої панелей.
- **`--lang ID`** — примусовий вибір мови інтерфейсу (наприклад, `en`, `ua` або власний пакет `<id>` із `lang/<id>.lang`).
- **`--choosedir=FILE`** — записати останній активний каталог у `FILE` перед виходом (зручно для функції shell-обгортки, щоб змінювати поточну директорію термінала після виходу з Duop).
- **`-V` / `--version`** — показати версію та інформацію про збірку.
- **`-L` / `--license`** — показати текст ліцензії MIT.
- **`-h` / `--help`** — коротка довідка CLI.

## 2. Інтерфейс і керування мишею

Екран Duop складається з п’яти зон:
1. **Верхня панель (`HeaderBar`)** — назва `Duop`, перемикач режиму панелей (`Dual` / `Preview`), кнопка прихованих файлів, поточна тема (`Alt+T`), мова (`Alt+L`), `Help` (`F1`) та `Quit` (`F10`).
2. **Файлові панелі (ліва та права)** — показують вкладки, поточний шлях, Git-гілку й статуси (`M`, `A`, `?`), колонки (`Назва`, `Розмір`, `Змінено`, `Права`), смугу прокрутки та підсумок позначених/усіх елементів.
3. **Панель живого перегляду (`Preview`, `F9` / `Ctrl+P`)** — замінює неактивну панель і миттєво показує вміст файлу під курсором (текст, ELF64-інформація, HEX або зображення).
4. **Рядок стану (`StatusBar`)** — шлях, ціль символьного посилання (symlink), підказки або тимчасові повідомлення про операції.
5. **Нижня панель клавіш (`FunctionBar`)** — інтерактивні кнопки `F1`–`F10`, на які можна натискати мишкою.

### Підтримка миші (SGR 1006)
- **Лівий клік** — вибір рядка, перемикання активної панелі, сортування по кліку на заголовку колонки, перетягування повзунка скролбару, натискання кнопок у `HeaderBar` / `FunctionBar` / діалогах.
- **Подвійний клік** — вхід у теку/архів або відкриття файлу у `F3`-переглядачі.
- **Перетягування (Drag & Drop)** — перетягування файлу з лівої панелі в праву (і навпаки) для копіювання/переміщення.
- **Правий клік** — виділення та відкриття контекстного меню (Перегляд, Копіювати, Перемістити, Копіювати шлях у буфер через OSC 52, Видалити).
- **Колесо миші** — прокручування списків, діалогів, тексту та масштабування/панорамування зображень.

## 3. Навігація, вкладки та пошук

- **Базова навігація**: стрілки / `j`/`k`, `PgUp`/`PgDn`, `Home`/`End` (`g`/`G`), `Enter` (відкрити теку чи архів), `Backspace` (`..`), `~` (`$HOME`), `Tab` (перемкнути панель).
- **Вкладки**: `Ctrl+T` відкриває нову вкладку в активній панелі, `Ctrl+W` закриває поточну вкладку (кожній вкладці зберігаються власний шлях, курсор, сортування і фільтр).
- **Історія та переходи**:
  - `Alt+←` / `Alt+→` — назад / уперед по історії переходів активної панелі.
  - `Ctrl+G` — ручне введення шляху (`Go to path`).
  - `Ctrl+D` — закладки каталогів (`Bookmarks`).
  - `z` — швидкий перехід за частотою та недавністю відвідування (`Frecency`).
- **Фільтрація та приховані файли**:
  - `/` — живий фільтр списку за назвою (`Esc` скидає фільтр або перериває потокове завантаження великого каталогу).
  - `.` або `Ctrl+H` — показати/сховати файли з крапкою (`dotfiles`).
- **Пошук і команди**:
  - `Ctrl+F` — рекурсивний пошук файлів за маскою імені та/або вмістом (`grep`).
  - `Alt+P` — нечіткий пошук файлів (`Fuzzy Finder`).
  - `Ctrl+K` — палітра команд (`Command Palette`) для швидкого запуску дій за назвою.

## 4. Файлові операції, фонові завдання та кошик

- **Базові дії**:
  - `Space` / `Insert` — позначити/зняти позначення з файлу; `*` / `Ctrl+A` — з усіх файлів.
  - `F2` — перейменувати; `Ctrl+N` — створити порожній файл; `F7` — створити теку (`mkdir`).
  - `F5` — копіювати; `F6` — перемістити (зокрема рекурсивно для тек і між різними файловими системами `-EXDEV`).
  - `F8` / `Delete` — видалити (з підтвердженням; підтримується безпечне відновлення через `Ctrl+Z` для операцій у кошик).
  - `F4` — відкрити файл у зовнішньому редакторі `$EDITOR` (за замовчуванням `vi`).
- **Атрибути та посилання**:
  - `Alt+A` — змінити права доступу (`chmod`).
  - `Alt+S` / `Alt+H` — створити символьне (`symlink`) або жорстке (`hardlink`) посилання.
  - `Alt+I` — детальна інформація про файл/теку (розмір, inode, права, час, контрольні суми).
- **Фонові завдання (`Alt+J`)**: великі операції `F5`/`F6`/`F8` виконуються у фоні з прогрес-діалогом (можна поставити на паузу, згорнути у фон або скасувати). При конфлікті імен відкривається діалог вибору (`Перезаписати`, `Пропустити`, `Перейменувати`, застосувати для всіх).
- **Кошик (`F8` / `Delete`, `Ctrl+Z`)**: файли переносяться до `~/.local/share/Trash` за специфікацією freedesktop.org Trash 1.0 (`files/` + `info/*.trashinfo` з відсотково закодованим `Path` та `DeletionDate` у UTC), тож кошик сумісний з іншими файловими менеджерами. `Ctrl+Z` повертає останній видалений елемент; якщо на старому місці вже є файл із такою назвою, нічого не перезаписується — елемент лишається в кошику, а рядок стану повідомляє про це.
- **Безпечний перезапис**: «Перезаписати» у діалозі конфлікту спершу пише нову версію в тимчасовий файл у теці призначення й підміняє цільовий файл через `rename` лише після повного копіювання — скасування, збій чи `SIGKILL` лишають стару версію недоторканою. Якщо в теці немає права запису (а сам файл доступний для запису), файл перезаписується «на місці». Через підміну змінюється inode: жорсткі посилання на старий файл зберігають стару версію.
- **Спеціальні файли**: канали (FIFO), сокети та пристрої не копіюються й не переносяться; FIFO читається лише у фоновому завданні (його можна скасувати). Інакше показується повідомлення «Спеціальний файл (канал/сокет/пристрій) не можна так копіювати чи переносити».
- **Масове перейменування (`Alt+B`)**: пакетне перейменування позначених файлів за шаблоном (наприклад `{n}.{ext}`) або пошуком/заміною з живим попереднім переглядом перед записом на диск.

## 5. Переглядач (`F3`), Preview (`F9`) та Hex-редактор

- **Текстовий переглядач**:
  - Великі файли відображаються через read-only `mmap` без завантаження всього файлу в RAM (миттєве відкриття та перехід `Home`/`End`/`PgDn`).
  - Підтримується підсвічування синтаксису (`C`, `asm`, `Python`, `JSON`, `Markdown` тощо).
  - Для виконуваних/об’єктних файлів у Preview працює вбудований **ELF64-інспектор**.
- **Hex-режим і вбудований Hex-редактор**:
  - Натисніть `H` у переглядачі (або `Alt+V` у Preview) для перемикання `Текст ↔ HEX`.
  - У `F3`-переглядачі натисніть **`E`**, щоб увімкнути редагування байтів: вводьте символи `0-9`, `a-f`, скасовуйте зміни через `Ctrl+Z` і зберігайте на диск через `Ctrl+S`.
- **Перегляд зображень**:
  - Підтримувані формати (чистий асемблер без зовнішніх бібліотек): **PNG**, **JPEG**, **GIF**, **BMP**, **PPM/PNM**, **TGA**, **QOI**.
  - Автоматичний вибір графічного протоколу термінала:
    1. **Kitty Graphics** (`kitty`, `WezTerm`, `Ghostty`) — повноколірне RGBA-зображення з плавним GPU-кропом при прокрутці.
    2. **Sixel** (`Foot`, `Konsole`, `XTerm`, `mlterm`) — адаптивна палітра з квантуванням.
    3. **2×2 Quadrant Blocks** — універсальний TrueColor-фолбек для будь-якого термінала.
    4. **Braille (`B`)** — перемикач монохромного деталізованого режиму.
  - Керування у `F3`: `+`/`=` та `-`/`_` (масштаб 25%–800%), `1` (`100%`), `0`/`f` (вписати у вікно), стрілки/`PgUp`/`PgDn` (панорамування), `O` (відкрити зовнішньою програмою).
  - За потреби протокол можна зафіксувати змінною середовища `DUOP_IMG_MODE` (`kitty`, `sixel`, `halfblock`, `blocks`/`quad`; режим Braille перемикається клавішею `B` у переглядачі `F3`).

## 6. Архіви, аналіз диска та порівняння

- **Віртуальна ФС архівів (VFS)**: натисніть `Enter` на `.tar`, `.tar.gz` (`.tgz`) або `.zip`/ZIP64, щоб переглядати вміст архіву як звичайну теку та відкривати файли через `F3` із потоковим розпакуванням і перевіркою CRC-32. Розмір архіву, кількість елементів і розмір елемента не обмежені (архів відображається в пам'ять, список теки будується бінарним пошуком; `.tar.gz` розпаковується один раз у безіменний тимчасовий файл, до 512 МіБ). Підтримуються довгі імена (ustar-префікс, GNU, PAX), UTF-8 і CP437 у zip, посилання та спеціальні файли (показуються, але не створюються); зашифровані або стиснені методом, що ще не реалізований (bzip2, LZMA, zstd), елементи показуються, а `F3` пояснює, чому їх не відкрито. Елементи з `..` у шляху та zip-елементи, що перекриваються, ніколи не показуються. Пошкоджений або неповний архів відкривається з тим, що вдалося прочитати, і повідомленням про це.
- **Розпакування**: `F5` у панелі-архіві (на `..` — уся тека), `Alt+F9` на файлі-архіві (уся архівна збірка; якщо в корені кілька елементів, створюється підтека `<ім'я>/`, тож «tarbomb» не засмітить теку). Робота йде у фоновому процесі з діалогом прогресу (`Esc`/`b` — у фон, `c` — скасувати); конфлікти імен — діалог «Перезаписати / Пропустити / Перейменувати». Безпека: шляхи з `..`, пристрої/FIFO, символічні посилання назовні та жорсткі посилання на сторонні файли не створюються (рахуються в повідомленні «N елемент(ів) не вдалося використати»); запис іде крізь `openat(O_NOFOLLOW)`, тож жоден symlink не перенаправить файл; кожен файл пишеться у тимчасовий `.duop-part-…`, перевіряється за CRC-32/розміром і лише тоді отримує ім'я; setuid/setgid знімаються, застосовується `umask`, відновлюються часи зміни. Відмова до початку запису: не вистачає місця, або архів розпаковується більш ніж у 1000 разів і більше за 1 ГіБ (бомба розпакування).
- **Перевірка архіву** (`Alt+Shift+F9`): повний декод усіх елементів із перевіркою контрольних сум без запису на диск. Усередині архіву панель працює **лише на читання**: `F5`/`F6`/`F8` показують повідомлення «Archive is read-only» замість діалогу (розпакування через `F5`/`Alt+F9` і пакування через `Alt+F5` — за планом [ARCHIVE_TOOLS_PLAN.md](ARCHIVE_TOOLS_PLAN.md)).
- **Використання диска (`Alt+D`)**: рекурсивно підраховує місце, яке кожна підтека реально займає на диску (як `du`: зайняті блоки, тож розріджені файли й `/proc/kcore` не роздувають підсумок; блоки самих тек враховано; жорсткі посилання рахуються один раз), сортує за спаданням і малює візуальні індикатори заповнення. У точки монтування псевдо-ФС (`proc`, `sysfs`, `cgroup`…), FUSE, `squashfs` (snap), `overlay` і мережевих ФС аналіз не заходить — вони лише повторюють дані, що вже лежать деінде; `tmpfs` рахується. Якщо підрахунок триває довше 0,3 с (змінна `DUOP_DU_PROGRESS_MS`), з'являється вікно «Аналіз розміру тек»: скільки тек верхнього рівня готово, смуга прогресу та лічильники переглянутих тек, файлів і байтів, що оновлюються щосекунди кілька разів. `Esc` скасовує підрахунок — панель повертається до звичайного списку.
- **Порівняння каталогів (`Alt+=`)**: підсвічує файли, що відрізняються або відсутні між лівою та правою панелями.

## 7. Термінал, меню користувача та Git

- **Вбудований термінал (`Ctrl+``)**: відкриває інтерактивну PTY-панель безпосередньо в Duop із синхронізацією робочого каталогу активної панелі.
- **Зовнішня оболонка (`Ctrl+O`)**: тимчасово передає термінал `$SHELL` (повернення в Duop після `exit`).
- **Менеджер пакетів (`Alt+K`)**: встановлення, перевірка SHA-256, оновлення й запуск зовнішніх розширень (`tool`), мовних пакетів (`lang`) та розкладок (`layout`) — див. [EXTENSIONS_GUIDE.md](EXTENSIONS_GUIDE.md).
- **Меню користувача (`Alt+U`)**: швидкий запуск налаштованих користувачем команд та встановлених розширень.
- **Макроси в командах** (меню користувача, правила відкриття): `%f` — ім’я поточного файлу, `%p` — повний шлях, `%d` / `%D` — тека активної / протилежної панелі, `%F` (або `%s`) — усі позначені файли (або поточний), `%%` — символ `%`. Значення екрануються з урахуванням лапок у шаблоні (без лапок, `'…'`, `"…"`), тож ім’я файлу з пробілами, лапками, `$(…)` чи `;` не може змінити команду. Підстановка або виконується повністю, або команда не запускається: якщо результат не вміщується в буфер, рядок стану показує «Команда задовга: не виконано».
- **Git-інтеграція**: у заголовку панелі показується поточна гілка, а біля файлів — статуси (`M`, `A`, `?`). Запуск `git status` ізольований: `core.fsmonitor` вимкнено, stdin — `/dev/null`, ліміт часу 2,5 с (після перевищення Git-індикація вимикається до перезапуску). Статус показується лише для довірених репозиторіїв: `.git` має бути справжньою текою, а локальний конфіг не повинен містити `[filter]` чи `[include]` (вони можуть виконувати довільні команди) — інакше гілка й статуси не показуються.

## 8. Мови, теми та розкладки клавіатури

- **Теми (`Alt+T`)**: `Tokyo Night`, `Catppuccin`, `Emerald` (24-бітний TrueColor).
- **Мови (`Alt+L`)**:
  - Базова англійська вбудована у бінарник; інші мови підвантажуються з файлів `lang/*.lang` (постачається [lang/uk.lang](../lang/uk.lang)).
  - Додаткові мовні пакети можна класти у `~/.config/duop/lang/<id>.lang` або вказати шлях через `DUOP_LANGS`.
- **Розкладки клавіатури**:
  - [layouts/uk.layout](../layouts/uk.layout) автоматично відображає `ЙЦУКЕН` на латинські клавіші для всіх гарячих клавіш (введення тексту в полях вводу не змінюється).
  - Власні розкладки можна додавати у `~/.config/duop/layouts/<name>.layout` або через `DUOP_LAYOUTS` без перезбірки програми.
- **Конфігурація**: налаштування зчитуються з `~/.config/duop/duoprc` (або шляху в `DUOP_CONFIG`). Файл застосовується повністю до 1 МіБ; більший файл обрізається по останньому повному рядку, а рядок стану показує попередження «Файл налаштувань завеликий: решту проігноровано».
