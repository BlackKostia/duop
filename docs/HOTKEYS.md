# Посібник по гарячих клавішах Duop

Усі гарячі клавіші (зокрема `Alt+...` та однолітерні) працюють **незалежно від поточної розкладки клавіатури** (вбудована підтримка `ЙЦУКЕН` через `layouts/uk.layout` та користувацькі `~/.config/duop/layouts/*.layout`).

---

## 1. Функціональні клавіші (`F1`–`F10`)

| Клавіша | Дія |
| :--- | :--- |
| **`F1`** | Довідка / інструкція з клавішами та інформація про програму |
| **`F2`** | Перейменувати файл або теку під курсором |
| **`F3`** | Перегляд файлу (текст / hex / зображення) |
| **`F4`** | Редагувати файл у зовнішньому редакторі (`$EDITOR`, за замовчуванням `vi`) |
| **`F5`** | Копіювати позначені файли або елемент під курсором у протилежну панель; у панелі-архіві — **розпакувати** їх (на `..` — усю теку архіву) |
| **`F6`** | Перемістити позначені файли або елемент під курсором у протилежну панель |
| **`F7`** | Створити нову теку (`mkdir`) |
| **`F8`** / **`Delete`** | Видалити позначені файли або елемент під курсором |
| **`F9`** | Увімкнути / вимкнути панель живого перегляду (`Preview`) |
| **`F10`** | Вийти з програми |

---

## 2. Навігація у файловій панелі

| Клавіша | Дія |
| :--- | :--- |
| **`↑`** / **`k`** | Перемістити курсор угору |
| **`↓`** / **`j`** | Перемістити курсор униз |
| **`PgUp`** / **`PgDn`** | Прокрутити список на одну сторінку вгору / вниз |
| **`Home`** / **`g`** | Перейти на перший елемент списку |
| **`End`** / **`G`** | Перейти на останній елемент списку |
| **`Enter`** | Увійти в теку або архів (`.tar`, `.tar.gz`, `.zip`) |
| **`Backspace`** | Повернутися на рівень вище (`..`) |
| **`~`** | Перейти в домашню теку (`$HOME`) |
| **`Tab`** / **`Shift+Tab`** | Перемкнути активну панель (ліва ↔ права, коли `Preview` вимкнено) |
| **`Alt+←`** / **`Alt+→`** | Історія каталогів активної панелі: назад / вперед |
| **`Esc`** | Скасувати активний потік завантаження або очистити фільтр |

---

## 3. Позначення файлів і пошук

| Клавіша | Дія |
| :--- | :--- |
| **`Space`** / **`Insert`** | Позначити / зняти позначення з файлу під курсором |
| **`*`** / **`Ctrl+A`** | Позначити / зняти позначення з усіх файлів у панелі |
| **`/`** | Увімкнути живий фільтр списку в активній панелі |
| **`.`** / **`Ctrl+H`** | Показати / приховати приховані файли (dotfiles) |
| **`z`** | Швидкий перехід за частотою використання (Frecency) |
| **`Ctrl+F`** | Пошук файлів / вмісту (`SearchDialog`) |
| **`Ctrl+K`** | Палітра команд (`Command Palette`) |
| **`Alt+P`** | Нечіткий пошук файлів (`Fuzzy Finder`) |

## 4. Вкладки, інтерфейс та утиліти

| Клавіша | Дія |
| :--- | :--- |
| **`Ctrl+T`** | Відкрити нову вкладку в активній панелі |
| **`Ctrl+W`** | Закрити поточну вкладку |
| **`Ctrl+G`** | Перейти за вказаним шляхом (`Go to path`) |
| **`Ctrl+D`** | Закладки каталогів (`Bookmarks`) |
| **`Ctrl+N`** | Створити новий порожній файл |
| **`Ctrl+R`** | Оновити вміст обох панелей |
| **`Ctrl+P`** | Увімкнути / вимкнути панель перегляду (`Preview`, аналог `F9`) |
| **`Ctrl+Z`** | Скасувати останнє видалення/операцію через кошик (`Undo`) |
| **`Ctrl+O`** | Запустити зовнішню оболонку (`$SHELL`) |
| **`Ctrl+` `** | Відкрити / приховати вбудовану панель термінала |
| **`Ctrl+Q`** / **`Ctrl+C`** / **`q`** / **`Q`** | Вийти з програми |
| **`Alt+T`** | Змінити тему кольорів (`Theme`) |
| **`Alt+L`** | Перемкнути мову інтерфейсу (`EN` ↔ `UA`) |
| **`Alt+V`** | Перемкнути режим панелі перегляду (`Image` / `Hex` / `Text`) |
| **`Alt+D`** | Режим аналізу використання диска (`Disk Usage`); довгий підрахунок показує вікно прогресу, `Esc` — скасувати |
| **`Alt+=`** | Порівняння каталогів лівої та правої панелей (`Dir Diff`) |
| **`Alt+B`** | Масове перейменування (`Bulk Rename`) |
| **`Alt+K`** | Менеджер пакетів та розширень (`Package Manager`) |
| **`Alt+F9`** | Розпакувати архів під курсором (або позначене в панелі-архіві) у протилежну панель; архів із кількома елементами в корені розпаковується в підтеку `<ім'я архіву>/` |
| **`Alt+Shift+F9`** | Перевірити архів (`Test Archive`): кожен елемент розпаковується в нікуди й звіряється з CRC-32/розміром; на диск нічого не пишеться |
| **`Alt+U`** | Меню користувача (`User Menu`) |
| **`Alt+J`** | Менеджер фонових завдань (`Tasks`) |
| **`Alt+A`** | Змінити права доступу (`chmod`) |
| **`Alt+I`** | Детальна інформація про файл/теку (`Info`) |
| **`Alt+S`** | Створити символьне посилання (`symlink`) |
| **`Alt+H`** | Створити жорстке посилання (`hardlink`) |

## 5. Переглядач файлів (`F3` / `ViewerDialog`)

### Загальні та текстовий режим
| Клавіша | Дія |
| :--- | :--- |
| **`↑`** / **`k`**, **`↓`** / **`j`** | Прокрутити на 1 рядок угору / вниз |
| **`PgUp`**, **`PgDn`** / **`Space`** | Прокрутити на сторінку вгору / вниз |
| **`Home`** / **`End`** | На початок / у кінець файлу |
| **`H`** | Перемкнути режим `Text` ↔ `Hex` |
| **`Esc`** / **`q`** / **`Q`** / **`F3`** / **`F10`** | Закрити переглядач |

### Режим перегляду зображень (`Image`)
| Клавіша | Дія |
| :--- | :--- |
| **`+`** / **`=`**, **`-`** / **`_`** | Збільшити / зменшити масштаб (25%–800%) |
| **`1`** | Масштаб 100% (`1:1`) |
| **`0`** / **`f`** | Підігнати зображення під розмір вікна (`Fit`) |
| **`←`** **`→`** **`↑`** **`↓`** | Панорамування зображення |
| **`PgUp`** / **`PgDn`** | Швидке вертикальне прокручування |
| **`Home`** / **`End`** | На початок (верхній лівий кут) / у кінець зображення |
| **`B`** | Перемкнути режим рендерингу Braille |
| **`O`** | Відкрити зображення у зовнішній програмі |

### Вбудований Hex-редактор (`Hex Edit`)
| Клавіша | Дія |
| :--- | :--- |
| **`E`** | Увімкнути / вимкнути режим редагування байтів |
| **`0`–`9`**, **`a`–`f`** | Введення шістнадцяткових напівбайтів (nibbles) |
| **`Ctrl+Z`** | Скасувати останню зміну байта |
| **`Ctrl+S`** | Зберегти зміни у файл |

## 6. Миша (SGR 1006)
- **Лівий клік** — вибір файлу, клік по смужках `HeaderBar`/`FunctionBar`, перетягування скролбару, Drag-and-Drop між панелями.
- **Подвійний клік** — вхід у теку/архів або відкриття файлу у `F3`-переглядачі.
- **Правий клік** — виділення та відкриття контекстного меню.
- **Колесо миші** — прокручування списку файлів, тексту або панорамування/зум зображення.
